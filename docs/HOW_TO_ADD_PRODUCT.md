# 添加新险种指南

本项目现在采用后台发布流：业务员提交产品草稿，系统生成条款向量；管理员审核后发布，前台用户才可以检索和咨询该产品。

接口契约见：[PRODUCT_WORKFLOW_API.md](./PRODUCT_WORKFLOW_API.md)。

## 快速步骤

### 1. 登录后台

启动项目后访问：

```bash
http://localhost:3000/admin/products
```

输入 `ADMIN_TOKEN` 完成登录。

### 2. 提交产品草稿

进入“提交产品草稿”页面：

```bash
http://localhost:3000/admin/add-product
```

可以选择两种录入方式：

- 上传 PDF 条款，系统解析后自动填充文本。
- 手动粘贴完整产品条款。

提交后系统会自动：

- 校验产品名称和条款文本。
- 抽取产品简介。
- 保存为草稿状态。
- 将条款语义分段。
- 生成向量并写入数据库。
- 清理旧搜索缓存。

### 3. 审核并发布

回到产品管理页，找到刚提交的草稿，点击“发布”。

发布后：

- 前台问答页会展示该产品。
- RAG 检索会命中该产品条款。
- 操作历史会记录发布动作和操作者。

如果条款需要修改，可以在产品管理页点击“编辑”，保存后系统会重新生成向量。

## 内容建议

- 使用完整条款，不要只粘贴营销摘要。
- 保留等待期、责任免除、投保年龄、缴费期、保险期间、赔付比例等关键数字。
- PDF 解析后先人工浏览一遍，修正明显的识别错误。
- 产品名称建议与正式条款保持一致，避免后续重复入库。

## 常见问题

**Q: 新提交的产品为什么前台看不到？**
A: 新产品默认是草稿，需要在产品管理页点击“发布”后才会对用户可见。

**Q: 可以更新已有产品吗？**
A: 可以。提交同名产品会作为草稿修订，重新生成条款和向量；发布后前台使用新版内容。

**Q: 还需要手动编辑 scripts/seedData.ts 吗？**
A: 不需要。`scripts/seedData.ts` 只适合本地初始化演示数据，线上产品新增走后台发布流。

**Q: 向量生成比较慢怎么办？**
A: 正常现象。完整保险条款会被拆成多段，每段都需要生成向量。页面会显示处理步骤，失败时可根据返回错误重试。
